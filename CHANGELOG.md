# Changelog

## 0.1.0

Initial local release candidate:

- Strict versioned Markdown parser and immutable document schema.
- Canonical evidence strings, provenance declarations and SHA-256 change checks.
- Macro-free DOCX rendering with hierarchy and citation Word styles.
- Exact overlapping highlight, underline, bold and small-font ranges.
- Local formatting profiles, CLI, batch conversion and Python API.
- Export text verification, passive integrity manifests and DOCX inspection.
- Automated tests, CI, release artifact building, examples and agent skills.

Interactive Microsoft Word/Verbatim workflows remain subject to the documented
manual compatibility matrix. This version does not claim universal macro support.
