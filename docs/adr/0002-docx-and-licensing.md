# ADR 2 Independent macro-free DOCX

Accepted. Use python-docx and independently authored OOXML style definitions. Pocket/Hat/Block/Tag map to Heading1–4; Cite follows the observed official release identifier and alias. Do not incorporate GPL Verbatim VBA or Debate.dotm into the MIT package. No Word installation is needed for export. Structural correctness and real macro interoperability are separate test gates.
